# 台股收盤速覽

收盤後一頁看完自選股的 Chrome 插件：日週月 K 線、壓力支撐、突破訊號、三大法人、融資融券、月營收與新聞。

## iPhone 版
用 Safari 打開 https://joemori.github.io/tw-stock-glance/ ，按「分享」再選「加入主畫面」，之後就像 App 一樣從桌面開啟。
- 底部四個分頁：收盤速覽（自選股依注意程度排序）、情報雷達、每週、設定。點自選股進入個股頁：K 線、今日重點、明天看哪些價位、訊號、法人、融資、營收、公告、新聞、關聯、對答案。
- 右上角三個 A 切換字體大小。
- 自選股、觀察清單、設定只存在手機上，不會上傳；第一次使用請到「設定」加入自選股。
- 個股資料直接向 FinMind 查詢；證交所、櫃買中心、集保等手機瀏覽器無法直接讀取的資料，由 GitHub Actions 每個交易日 17:05、21:45 整理成 data/*.json。

## 安裝（Chrome 插件）
1. 解壓縮到一個固定的資料夾（之後不要移動或刪除）。
2. Chrome 網址列輸入 `chrome://extensions`。
3. 打開右上角「開發人員模式」。
4. 點「載入未封裝項目」，選這個資料夾。
5. 把工具列的拼圖圖示裡的「台股收盤速覽」釘選出來。

## 使用
- 點工具列圖示看自選股一覽，點「開啟完整頁面」進入速覽頁。頁面上方三個大按鈕切換「收盤速覽」「情報雷達」「每週報告」。
- 預設自選股：台積電、聯發科、世芯-KY，可在左側新增或移除（自選股存在 Chrome 同步儲存，不在程式碼裡）。
- 第一次打開會抓自選股兩年資料（約 10 到 20 秒），再下載全市場近 60 個交易日行情給族群、同業與自動關聯使用（約 3 到 4 分鐘，右上角會顯示進度）。之後每天只補新的一天。
- 右上角查詢框可輸入代號或名稱（例如「玉晶光」）直接開啟；側欄新增也接受名稱。鍵盤 ← → 切換自選股，按 / 跳到查詢框。
- 點大盤概況列的加權、櫃買、美股半導體 ETF、美元／台幣，或關聯脈絡裡的美股與匯率卡片，會跳出走勢視窗（3 個月、1 年、2 年）與相關新聞。
- K 線上方的「疊加比較」可疊上大盤或關聯對象的走勢，看同期誰強誰弱。
- 情報雷達：從全市場公司公告與內部人轉讓申報，篩出處分資產、庫藏股、增資減資、接單、澄清、更正財報等值得注意的消息，換算每股影響，標出是否已反應在股價、與自選股的關係；可加入觀察清單與關鍵字。
- 指標成績單：每個交易日收盤後自動記下當天出現的指標，之後對答案，累積 2 到 3 個月後就看得出哪些指標在你的股票上比較準。
- 字體大小：頁面右上角「字 A A A」切換標準、大、特大，整頁等比例放大（版面、表格、圖表一起變），設定會同步到其他頁面與電腦。
- 畫面上有虛線底線的名詞，滑鼠移過去會顯示白話解釋。
- 自選股在左側欄，點一檔看細節；按 « 可收起側欄，收起後頂端改用股票按鈕切換。上方的跳轉列可以直接到各區塊。
- 休市日（含補假、颱風）不會自動更新；按重新整理後，狀態列會說明最新交易日之後哪幾天休市。
- 每週報告：速覽頁右上角或工具列視窗的「每週報告」，也可以列印或存成 PDF；用「週次」切換回看過去的週報。
- 關聯脈絡：每檔股票下方可新增關聯對象（台股或美股代號），按 × 移除。
- 關聯行事曆：每檔股票顯示本股與關聯公司未來 45 天的法說會、財報、除權息；可按「新增事件」自行加入。
- 通知：每個交易日 16:40 收盤更新、21:40 補融資融券，每週六 09:00 通知週報。
- 題材族群的成分股寫在 `lib/sectors.js`，可自行修改。
- 查詢太頻繁時 FinMind 會暫時擋下，可到 finmindtrade.com 免費註冊，把 token 填進「設定」。

## 更新版本
把新版檔案覆蓋到同一個資料夾，再到 `chrome://extensions` 按插件卡片上的重新載入。自選股與設定會保留。
